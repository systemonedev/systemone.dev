## The shift in one code block

A System 2 model hands you a string and asks you to trust it. A System 1 model hands you a
typed decision and a calibrated probability — so you can write ordinary deterministic code
around it.

<Tabs>
<TabItem label="System 1 (decision-native)">

```javascript title="firewall.js"
const decision = await jev.evaluate({
  input: rawLogData,
  categories: ['sql_injection', 'safe_traffic'],
});

if (decision.confidence > 0.95 && decision.category === 'sql_injection') {
  firewall.blockIP(request.ip);
} else {
  routeToHumanAnalyst(rawLogData);
}
```

No parsing. No retries. No `ONLY RETURN VALID JSON`. The branch is yours.

</TabItem>
<TabItem label="System 2 (generative)">

```javascript title="firewall-generative.js"
const res = await llm.chat({
  messages: [
    { role: 'system', content: 'You are a security classifier. ONLY RETURN VALID JSON...' },
    { role: 'user', content: rawLogData },
  ],
});

let decision;
try {
  decision = JSON.parse(stripCodeFences(res.choices[0].message.content));
} catch {
  return retryWithBackoff(rawLogData); // ...and hope round two parses
}

// `decision.confidence` is a number the model wrote down. It is not calibrated.
```

Three seconds, a parser, a retry loop, and a confidence score that means nothing.

</TabItem>
